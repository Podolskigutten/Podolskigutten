# Hi, I'm Lukas

I recently completed my master's degree in Cybernetics and Autonomous Systems at the University of Oslo. My thesis compared three frontier-based exploration strategies for autonomous robots navigating unknown environments, using WiFi signal strength to guide a Leo Rover toward a target. The system is built on SLAM Toolbox and Nav2, and was evaluated across hundreds of simulation runs and physical robot trials.
